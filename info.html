How to join

Subscribe to any one of our Twitch channels and you instantly unlock access to our Discord, game servers, and community events. After you sub, you’ll get a DM with your Discord invite link. Join up, and everything you need — server IPs, whitelists, events, updates — is inside. Follow the links below to get started

Game Nights

We host regular Game Nights where the community decides what we play. Before each stream, we drop a poll in Discord with a list of game options. Everyone votes, and we start the stream with the most‑voted game. If we wrap it up or get bored, we move down the list to the next highest pick and keep the fun rolling. All voting happens inside the Discord, so make sure you’re in there if you want your vote to count.
