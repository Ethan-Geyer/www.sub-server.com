Sub-Server Website

This repository contains the source code for the official Sub-Server website. The site serves as a central hub for players to discover our game servers, learn how to join, and connect with our Discord community.

## What’s Inside
- **Server Listings:** IPs, ports, and descriptions  
- **Join Guides:** Step‑by‑step instructions for new players  
- **Discord Access:** instructions
- **Responsive Layout:** Mobile‑friendly and lightweight  
- **Custom Branding:** Modified theme and layout to match Sub‑Server identity
