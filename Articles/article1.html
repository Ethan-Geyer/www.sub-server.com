Server Update — Website Improvements & Discord Cleanup

May 27th, 2026

A Better Experience Across the Board

We’ve been working behind the scenes to make both the website and the Discord feel cleaner, faster, and easier to navigate. This update focuses on organization, readability, and community identity — three things that matter as our Sub‑Server community keeps growing.

Website Updates: Reading Materials Now Supported

We’ve added new structure to the site so we can publish articles, updates, guides, and community posts in a clean, readable format. This includes:

  • Dedicated layout for long‑form content
  • Better spacing and typography for readability
  • New “New Entries” section for quick navigation
  • Support for ongoing updates and community posts

Discord Cleanup & Reorganization

The Discord has been fully cleaned up and reorganized to make it easier for everyone to navigate.

  • Channels grouped more logically
  • Old or unused channels archived
  • Roles and permissions cleaned up
  • Navigation simplified and decluttered

New Discord Server Tag: SUBS

To help identify and support our subscriber community, we’ve added a new server tag: SUBS. This tag highlights verified subscribers and helps us manage subscriber‑only areas, events, and perks.

What’s Next

We’re continuing to refine both the website and the Discord as the community grows. Expect more articles, guides, updates, spotlights, and events as we continue building the Sub‑Server experience.
